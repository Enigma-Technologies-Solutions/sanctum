ETS Enigma / Hash Check

Tool for Sanctum

Is it thefile?

Compare a downloaded file with the checksum its publisher gave you. Installers, disk images, firmware, documents. The file is read in this window and never leaves it.

Stays here

The file is read in small pieces and hashed on this computer. Nothing is uploaded, stored or sent.

Asks for nothing

No network, no devices, no storage. The approval screen in Sanctum is empty.

A match has limits

It shows the file is the one the checksum was made from. It does not show the checksum came from the publisher.

Step 1

Choose the file

Any size. Large files take a while, and you can stop at any time.

No file chosen.

Step 2

Paste the checksum

Optional. Paste one checksum, or the whole contents of a file such as SHA256SUMS. Without one, the tool only shows the file's hash.

Reads a plain hash, sha256: hash, GNU lines (hash name) and BSD lines (SHA256 (name) = hash).

Algorithm

SHA-256 is what most publishers use. A pasted checksum sets this by its length.
