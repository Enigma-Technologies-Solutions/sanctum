Two-factor codes, generated inside Sanctum. Your username and password never leave this window. They derive an AES-256 key that encrypts every secret before it is written to this tool's own storage. The tool asks for no network access. With a YubiKey and smart card access approved, secrets can live on the key instead, and codes are computed by the key.

This page needs the Web Crypto API. Sanctum provides it to every tool; in a browser, open the file over https://, http://localhost or file://.
Local storage is blocked in this browser (private mode or site data disabled). The vault will work for this window only and will be lost when it closes. Copy a backup to keep it.
Sanctum gives this tool its own storage, tied to the tool's identity in your library. Adding a new version of the tool keeps the vault. Deleting the tool from Sanctum and adding it again starts with empty storage, so copy a backup first.

Unlock your vault

Enter the username and password you chose when the vault was created. The fingerprint below is computed from what you type. If it matches the one you remember, the combination is right.

Case-insensitive. Only used locally, together with the password, to derive the key.

  • There is no recovery. Forgetting the password means the stored secrets cannot be decrypted.
  • Use at least 12 characters. A passphrase of four or more random words works well.
  • The same username and password always produce the same fingerprint and key, on any device.

04 · YubiKey

Codes computed by your key

The YubiKey OATH applet keeps each secret inside the key and returns only the code. Nothing about these accounts is stored in this tool. This needs Sanctum's smart card access, approved for the OATH (TOTP/HOTP) applet only.

Smart card access is not available to this tool. In Sanctum, open this tool's permissions and approve talk to your smart card: OATH (TOTP/HOTP) [a0000005272101], then reopen the window. Outside Sanctum this section stays off.

This key's OATH applet is protected by a password.

05 · Vault

Backup and password

Copy the encrypted vault to the clipboard as JSON, then paste it into a file or a password manager note. It stays encrypted; you need the same username and password to open it. Accounts stored on a YubiKey are not part of the backup.

Change the password. Everything is re-encrypted under a new key and the fingerprint changes.

Remove this vault from this tool's storage. This cannot be undone without a backup.

Key derivation: PBKDF2-SHA-256, 600,000 iterations, salt bound to the username, then HKDF-SHA-256 into an AES-256-GCM key and a separate fingerprint value. Codes: TOTP per RFC 6238. Storage: this tool's own localStorage origin in Sanctum, one encrypted record per vault. YubiKey accounts use the OATH applet through window.sanctum.smartcard.

Anyone with access to this user account's Sanctum data can copy the encrypted record and try passwords offline, so choose a long one. The vault locks after 5 minutes without activity.
