ETS Enigma / OTP Vault

Tool for Sanctum

Codes that stay here

Two-factor codes, generated inside Sanctum. Your username and password derive an AES-256 key that encrypts every secret before it is written to this tool's own storage. With a YubiKey and smart card access approved, secrets can live on the key instead, and the key computes each code.

This page needs the Web Crypto API. Sanctum provides it to every tool. In a browser, open the file from disk or from a secure (HTTPS) address.
Storage is blocked in this browser (private mode or site data turned off). The vault works for this window only and is lost when it closes. Copy a backup to keep it.
Sanctum gives this tool its own storage, tied to the tool's identity in your library. A new version of the tool keeps the vault. Deleting the tool from Sanctum and adding it again starts with empty storage, so copy a backup first.

Stays here

Your username and password never leave this window. Secrets are encrypted before they are stored, and codes are computed on this computer.

Asks for two things

Its own storage for the encrypted vault and, only if you use it, the OATH applet of a YubiKey. No network.

No recovery

If the password is forgotten, the stored secrets cannot be decrypted. Keep a backup and a long password.

Step 4: Codes from your YubiKey

The YubiKey OATH applet keeps each secret inside the key and returns only the code. Nothing about these accounts is stored in this tool. This needs Sanctum's smart card access, approved for the OATH (TOTP/HOTP) applet only.

Smart card access is not available to this tool. In Sanctum, open this tool's permissions and approve talk to your smart card: OATH (TOTP/HOTP) [a0000005272101], then reopen the window. Outside Sanctum this step stays off.

This key's OATH applet is protected by a password.

No accounts on this key yet. Add one in step 2 and choose YubiKey.
5

Step 5: Back up and look after the vault

Copy a backup

Copy the encrypted vault to the clipboard as JSON, then paste it into a file or a password manager note. It stays encrypted, and the same username and password open it. Accounts stored on a YubiKey are not part of the backup.

Change the password

Everything is encrypted again under a new key, and the fingerprint changes.

Delete the vault

Remove this vault from this tool's storage. Without a backup, this cannot be undone.

Enigma OTP Vault 1.0.3. Part of Sanctum, AGPL-3.0. Codes are TOTP as defined in RFC 6238. Icons from Lucide (ISC). Fonts Inter, Poppins and Space Mono (SIL OFL 1.1).

Key derivation: PBKDF2-SHA-256, 600,000 iterations, salt bound to the username, then HKDF-SHA-256 into an AES-256-GCM key and a separate fingerprint value. Storage: this tool's own localStorage origin in Sanctum, one encrypted record per vault. YubiKey accounts use the OATH applet through window.sanctum.smartcard.

Anyone with access to this user account's Sanctum data can copy the encrypted record and try passwords offline, so choose a long one. The vault locks after 5 minutes without activity.
