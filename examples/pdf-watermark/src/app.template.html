ETS Enigma / PDF Watermark

Tool for Sanctum

Mark everycopy.

Put a visible watermark on PDFs before you share them, with an ID that is different for each file and a name on every page. Passports, visas, contracts. It all happens in this window.

Stays here

Your PDFs are read and rewritten in this window. Nothing is uploaded, stored or sent anywhere.

Asks for nothing

No network, no devices, no storage. The approval screen in Sanctum is empty.

Deterrence only

Someone with a PDF editor can remove these marks, and a printout or screenshot drops the hidden ones.

Step 1

Choose your PDFs

Pick as many as you like. Each file is marked on its own.

Up to 200 MB each. Password protected files must be unlocked first.

Step 2

Set the watermark

The preview shows how the tiling lies on a page. The ID shown is an example.

Required. It is printed on every page, so a leaked copy leads back to the person it was made for.

Colour
Wording

Use {UID}, {DATE}, {RECIPIENT}, {PAGE} and {PAGES}. Letters outside the standard Latin set are replaced with a question mark, because the built in PDF font cannot draw them.

A4 page, as a viewer shows it.

Step 3

Mark and save

Marked files are saved to your Downloads folder. The original files are never changed.
