# Bundled fonts

Latin subsets, the same files the website serves from `web/assets/fonts/`.
Bundling them means the app makes no requests to Google Fonts.

| File | Family | Licence |
| --- | --- | --- |
| `Inter-var.woff2` | Inter (variable, 100 to 900) | SIL Open Font License 1.1 |
| `Poppins-600/700/800.woff2` | Poppins | SIL Open Font License 1.1 |
| `SpaceMono-400/700.woff2` | Space Mono | SIL Open Font License 1.1 |
